# Rocq/Coq candidate repos for ablation mining

60 candidates, non-math (systems / crypto / compilers / PL / hardware / distributed /
blockchain / program logics), ranked roughly by suitability for the corollary-ablation
miner: hand-written proofs with in-file lemma dependency structure.

Discovery: GitHub API sweep of `language:Coq` + `language:Rocq Prover` across star bands
(649 raw candidates, 246 after dropping forks/archived/math/courses), cross-checked against
a web deep-research pass. **The Rocq wiki project list is dead (last edited 2019) — do not
use it as a discovery channel.** Note the Iris family lives on GitLab and is invisible to
GitHub search.

## Caveats before mining

- **Autogenerated `.v` is the main trap.** fiat-crypto's field-arithmetic files, VST's
  `progs/` (clightgen output) and its vendored `compcert/`, and the formal-land
  `rocq-of-*` translators are machine-emitted: they have little hand-written lemma
  structure and must be path-filtered or the mined challenges will be junk.
- **Licenses are not uniformly permissive.** VST is NOASSERTION (custom Princeton
  license), BRiCk is a bespoke LGPL-2.1 + network addendum, vericert and forves are
  GPL-3.0, cfml is CC-BY-4.0. Review before redistributing any mined dataset.
- **`rocq-of-solidity` was checked and rejected**: ~99% machine-translated Yul/Solidity
  test files, only ~1 MB hand-written proof, and GPL-3.0.
- Build systems vary (dune / `_CoqProject` + Makefile / opam / nix); each repo needs its
  Coq/Rocq version pinned before `coqc` can validate an ablation, exactly as the Lean
  batch needed `lake build` first.
